# 宇浩輸入法・星陳

配方： ℞ a5corpii/yustar

Rime 星陳輸入方案

改编自 [宇浩输入法方案發佈仓库](https://github.com/forfudan/yuhao-ime-release)
及 [爛然星陳](https://shurufa.app/docs/star.html) 相關內容，
適合通過 [東風破](https://github.com/rime/plum) 安裝，
口令： `bash rime-install lotem/rime-zhengma`

碼表與原版相同，僅保留最基礎功能。啓用更多功能請使用原版宇浩輸入法方案或自建`yustar.custom.yaml`
