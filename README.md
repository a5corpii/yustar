# 宇浩輸入法・星陳

配方： ℞ a5corpii/yustar

## 說明

Rime 星陳輸入方案

改编自 [宇浩输入法方案發佈仓库](https://github.com/forfudan/yuhao-ime-release)
及 [爛然星陳](https://shurufa.app/docs/star.html) 相關內容。

碼表與原版相同，僅保留最基礎功能。啓用更多功能請使用原版宇浩輸入法方案或自建`yustar.custom.yaml`

## 安裝

安裝 [東風破](https://github.com/rime/plum) 後使用
口令： `bash rime-install a5corpii/yustar`

### 通用方式

安裝 [RIME](https://rime.im/) 後，複製碼表到用戶目錄，重新部署生效。

部署位置：

#### Windows 10+

```
    %APPDATA%\Rime
```

#### Mac OSX

```
    ~/Library/Rime
```

#### Linux

##### ibus-rime:

```
    ~/.config/ibus/rime
```

##### fcitx-rime:

```
    ~/.config/fcitx/rime
```

##### fcitx5-rime:

```
    ~/.local/share/fcitx5/rime
```
